# Customer Welcome Application

## Project Description
A simple customer welcome application developed using HTML, CSS, and JavaScript.

## Features
- Enter customer name.
- Validate empty customer name.
- Display personalized welcome message.
- Responsive user interface.
- Simple and clean design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure

learning-github/
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Enter a customer name.
5. Click Welcome Customer.
